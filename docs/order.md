# 指示

次の業務要件を満たすページを作成してください。

# 業務要件

- サービスが存在する。
- サービスを利用するユーザーを利用ユーザーとする。
- サービスを管理するユーザーを管理ユーザーとする。
- 管理ユーザーは利用ユーザーとなる。
- 利用ユーザーは複数のサービスにひも付きます。
- 利用ユーザーには課金のために1つだけオーダーが付きます

- 管理ユーザーは複数のサービスを管理します。
- 管理ユーザーはサービスごとに利用ユーザーを管理します。
- 管理ユーザーは利用ユーザーに紐づくオーダーを管理します。
  - ただし、(サービス, 利用ユーザー)毎に1つのオーダーは尽きません。
    利用ユーザー1に対して、に対して1つのオーダーがつきます。
    そのため、サービスのうちどれか1つだけがその利用ユーザーの管理サービス扱いとします。

- 管理ユーザーによっては、配下の利用ユーザーの
  サービスの管理権限を持っていないケースがあります。
  その場合は、オーダーを変更できません。

- 管理ユーザーは、毎月オーダーが終了するので、利用ユーザーのオーダーを新しいオーダーに置き換える操作を行いたいです。
  そのため、次の手順で一括変更します。
  1. オーダーを選択する。
  2. そのオーダーを利用しているユーザー一覧を表示する
  3. ユーザー一覧からオーダー変更対象のユーザーを選択する
  4. オーダーを変更する

  という操作を行いたいです。

- 表示が必要な情報は以下です。
  1. ユーザー名
  2. メールアドレス
  3. オーダーが変更可能かどうか
  4. オーダーの有効期間
  5. そのユーザーの利用サービス(折り畳みで表示など、良い感じに出力してください)
     1. サービス名
     2. オーダーの管理サービスかどうか(アイコンでわかりやすく表示したい。)
