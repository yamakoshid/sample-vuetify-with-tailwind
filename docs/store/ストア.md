- Nuxt.jsを利用する
- Piniaストアを利用し、ページ間でデータを持つ

## 階層構造を持つ

- /service
  - /service/users
  - /service/functions
    - /service/functions/function-details

## 階層構造を持つデータ例

- 組織・権限管理
  - useGroupStore
  - 企業情報・契約プラン
    - 基本情報変更
    - ライセンス確認
  - ユーザー管理
    - ユーザー一覧
  - 権限・ロール - 管理者/一般ユーザーの権限編集

# 親

- 入力項目
  - トグルスイッチなど
- 子の詳細ボタン
  - クリックすると子に遷移する
- 送信ボタン
- キャンセルボタン

## 子

- 入力項目
  - トグルスイッチなど
- キャンセルボタン
  - 入力データをクリアして親に戻る。
  - 孫のデータも設定をクリックした後に戻る。
- 設定ボタン
  - 入力データを設定して親に戻る

### 孫

- 入力項目
  - テキストフィールドなど
- キャンセルボタン
  - 入力データをクリアして子に戻る。
- 設定ボタン
  - 入力データを設定して子に戻る
